## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.19，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離資料目錄先安裝 1.1.18，再升級至 1.1.19，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；本次新增介面譯文與燒錄提示正確替換，通過。
