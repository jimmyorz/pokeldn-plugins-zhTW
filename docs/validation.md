## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.23，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離資料目錄先安裝 1.1.22，再升級至 1.1.23，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；本次新增開發板提示與重新偵測紀錄正確顯示，通過。

## 限制與待確認事項

- 本次未啟動完整桌面或行動版 GUI，也未執行實際 PKHeX 服務、iOS 的 AOT 版本、Switch／開發板硬體或燒錄；Flet 驗證限於語系設定、元件及回呼；XWayland 開窗與燒錄後重新偵測均未實機驗證。
- Android 裝置辨識已納入 S2；上游 Android 介面原文仍未列入 S2，暫沿用原文譯法，未做實機確認。較舊版本若使用先前已移除的主字串鍵，對應提示會回退至英文。既有英文顯示範圍見 `docs/translation.md`。
