## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.16，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.15，再升級至 1.1.16，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；2 筆新增譯文均正確替換，通過。

## 限制與待確認事項

- 本次未執行完整 GUI、實際 PKHeX 服務、Switch／開發板硬體及 ROM／存檔傳輸；按鈕及欄位測試未涵蓋實際畫面的排版與觸控。
- 1.1.16 對齊 0.63.1 的鍵值。舊版 App 若仍查詢已移除的 4 個鍵，該處會回退英文；已用舊鍵及原文驗證回退，未啟動舊版完整 GUI。使用 0.63.0 如需保留這四處譯文，可繼續使用 1.1.15。
- 既有英文顯示範圍見 `docs/translation.md`，本次未擴大文件內文或原始紀錄的翻譯範圍。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
