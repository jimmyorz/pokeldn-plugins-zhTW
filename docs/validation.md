## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.25，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離資料目錄先安裝 1.1.24，再升級至 1.1.25，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；本次新增的初訓家選項、拒絕提示、回退對話框、韌體提示及第三世代配信譯文正確顯示，通過。

## 限制與待確認事項

- 本次未啟動完整桌面或行動版 GUI，也未執行實際 PKHeX 服務、iOS 的 AOT 版本、Switch／開發板硬體或燒錄；Flet 驗證限於語系設定、元件及回呼，未實際與主機交換、發送配信、驗證各遊戲的合法性結果，或進行硬體燒錄。
- `[receiver]` 等交換診斷紀錄會保留上游英文，對話框內未收錄的底層原因也可能沿用原文。較舊的 pokeldn 仍可安裝本語言包，但已從 0.67.0 移除的「將我設為初訓家」按鈕會回退至英文。遊戲內實際接收的卡片文字與終端機參數說明沿用上游；App 的配信介面已補譯。其它英文顯示範圍見 `docs/translation.md`。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
