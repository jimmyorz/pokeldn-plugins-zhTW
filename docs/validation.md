## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.12，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.11，再升級至 1.1.12，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；本次修改的 76 筆譯文均正確替換，通過。

- 配信已選取清單及標題搜尋仍直接使用原文；更新程式的兩段資料夾保護警告、單隻寶可夢檔案過大的錯誤也未經語言包替換，無法只靠新增對照生效。配信標題的實際 .NET 清單仍待完整 App 確認。
- 既有英文顯示範圍見 `docs/translation.md`，本次未擴大文件內文或原始紀錄的翻譯範圍。
