## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.26，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離資料目錄先安裝 1.1.25，再升級至 1.1.26，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；本次新增的初訓家開關與說明正確顯示，通過。

## 限制與待確認事項

- 本次未啟動完整桌面或行動版 GUI，也未執行實際 PKHeX 服務、iOS 的 AOT 版本、Switch／開發板硬體或燒錄；Flet 驗證限於語系設定、元件及回呼，未實際與主機交換，或驗證交換時 PKHeX 對各遊戲的合法性結果。
- `[receiver]` 等交換診斷紀錄會保留上游英文，對話框內未收錄的底層原因也可能沿用原文。較舊的 pokeldn 仍可安裝本語言包，但 0.69.0 已移除的交換卡片選項及相關提示會回退至英文。pokeldn 0.68.0 可繼續使用原 1.1.25 封裝。其它英文顯示範圍見 `docs/translation.md`。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
