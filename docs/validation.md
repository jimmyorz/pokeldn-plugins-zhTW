## 增量檢查範圍

原基準至最新 main 共 18 筆提交、33 個變更檔案；排除 AltStore 清單後，依其餘 32 個檔案的差異定位翻譯來源與必要相依內容。比對遠端 tree 與提交差異清單，確認新增、刪除、改名及內容變動一致。沿用 540 個雜湊一致的快取檔案，下載的變更檔案也均核對 Git blob SHA，未重新掃描未變更的遊戲模組。

- 主英文表新增 17 個鍵值、移除 6 個：包含開發板就緒、證章、遊戲版本選擇、匯出提示；五組遊戲名稱拆成十個版本名稱，並替換集友圈野生寶可夢生成說明。既有同鍵值原文與格式變數沒有變更。變更 Python 檔案中的 1,272 個固定字串 `tr()` 呼叫，其鍵值與英文 fallback 均符合新版主字串表。
- `pokeldn/trade_back.py` 新增返還回合的狀態卡片；標題沿用「換回原寶可夢」，新增再次交換的操作說明。
- `gui/localization.py` 現在會翻譯回覆的 `note`，補上固定 PID 導致異色狀態改變、配信寶可夢必須保留 PID 等三種原有說明。原始英文與資料中的 `canonical` 保持不變。
- `gui/views/pokemon.py` 的遭遇標籤開始翻譯版本名稱。既有對照可處理大多數名稱，另外補入 Let's Go 皮卡丘、Let's Go 伊布、Sword 與 Shield 四筆。遭遇類型維持在標籤處翻譯一次；既有 GO 範本無需變更。
- `messages.toml` 共新增 8 筆、替換 1 筆過時的生成說明；五組遊戲名稱仍供文件側邊欄使用，保留其對照。`terms.toml` 與 `templates.toml` 無需修改。
- `bin/sv_join.py` 新增 `--spawn-mark`，四個工具共用此入口，`help.toml` 補入 4 筆說明。實際工具清單與 parser 比對沒有既有工具 ID、選項名稱或說明刪除、更名或改寫。
- `services/pkhex/Wild.cs` 新增 42 種野生證章，名稱從請求語系的 `GameStrings.Ribbons` 取得。依 PKHeX.Core 26.10.18 的 `RibbonIndex` 及繁中資源核對，全部 42 種均有中文名稱；53 為正午之證、58 為降雨之證、97 為不振之證。語言包只補翻譯欄位標題、無證章選項與工具說明，不複製整套名稱資料。
- `services/pkhex/Program.cs` 的遭遇地點改用請求語系的 `strings.GetLocationName()`。已檢查原有 `zh-TW` → `zh-Hant` 傳遞及新的查詢路徑；配信卡標題仍沿用原始資料。
- `docs/architecture.md`、`docs/gui.md`、`docs/sv_union_circle.md` 的 front matter 均未變，沒有新增或更名的遊戲側邊欄標題。
- Plugins API 仍為 1.12。外掛格式、載入、替換核心、簽章、Sources 解析及封裝工具沒有變更；PKHeX.Core 仍為 26.10.18，相關依賴清單也沒有變更。
- 其它更新為野生寶可夢的地面位置與移動、天氣證章合法性、控制項排列及檔案匯出方式。新增的城鎮等待文字只寫入 CLI／紀錄，沒有可由語言包替換的顯示路徑，因此未新增無效對照。

`docs/translation.md` 已移除初訓家說明與遭遇版本名稱仍無法翻譯的舊限制，補充證章及遭遇地點由 PKHeX 提供名稱，並同步先前已確認的斜線規則。`docs/maintenance.md` 保持不變。

## 限制與待確認事項

- 本次未執行完整 GUI、實際 PKHeX 服務、Switch／開發板硬體或真實瀏覽器／手機的檔案儲存操作。環境未安裝 .NET、Flet 與 esptool，Python 檢查使用現有依賴（PyCryptodome 4.1.0、Trio 0.34.0），未以全套上游鎖定版本啟動 App。
- 遭遇地點及證章語系相容性依來源與資源檢查；模擬服務測試只確認語系傳遞與回覆處理，不代表已執行 .NET 地點查詢或寶可夢合法性分析。
- 野生寶可夢在實機上的生成位置、移動、天氣證章與交換行為未在本環境實測。上游報告的實機結果不列為本語言包的測試成果。
- 部分遭遇類型細節、配信卡片標題，以及「讀取我的資料」的英文遊戲名稱仍受既有顯示路徑限制；只修改語言包無法讓所有原始資料改為中文。
