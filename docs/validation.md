## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.14，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.13，再升級至 1.1.14，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；兩筆 `--rom-live` 說明均正確替換，通過。

- 本次未執行完整 GUI、實際 PKHeX 服務、Switch／開發板硬體及 ROM／存檔傳輸。兩筆譯文的驗證限於選項查詢、安裝及新程序載入。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
