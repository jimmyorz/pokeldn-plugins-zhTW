- 獎章描述使用實際 `gift_description()` 驗證單個與多個獎章；編號下界、上界與數量上限錯誤共 3 例均正確翻譯。

## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.11，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.10，再升級至 1.1.11，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；新增主字串、訊息對照及配信形態標題均正確替換，通過。

- 本次未執行完整 GUI、實際 PKHeX 服務、Switch／開發板硬體、遊戲封裝讀取或 ROM／存檔傳輸。環境未安裝 .NET、Flet 與 esptool，Python 檢查使用現有依賴，未以全套上游鎖定版本啟動 App。
- 銀行匯入、格式轉換與複製交換行為僅依來源差異檢查，未實際建立、匯入或交換寶可夢；模擬錯誤回應只驗證翻譯路徑，不代表 .NET 合法性分析或實機功能通過。
- 獎章選項、交換複製與性別顯示的文字查詢已核對，但未實際檢視新 GUI 的排版、尺寸與換行。
- 配信已選取清單及標題搜尋仍直接使用原文；更新程式的兩段資料夾保護警告、單隻寶可夢檔案過大的錯誤也未經語言包替換，無法只靠新增對照生效。配信標題的實際 .NET 清單仍待完整 App 確認。
- 既有英文顯示範圍見 `docs/translation.md`，本次未擴大文件內文或原始紀錄的翻譯範圍。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
