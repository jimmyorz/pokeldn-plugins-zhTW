## 增量檢查範圍

以原基準至最新 main 的差異為主，共 13 筆提交、62 個變更檔案；排除 AltStore 清單後，依其餘 61 個檔案的差異定位翻譯來源與必要相依內容。未重新掃描未變更的遊戲模組。遠端 tree 與比較結果的變更清單一致，沿用快取與下載的變更檔案均核對 Git blob SHA。

- 主英文表只新增 `pokemon.clear = "Clear"`，沒有刪除、改名、同鍵值原文或格式變數變更；譯為「清除」，與既有清除按鈕一致。
- `gui/views/pokemon.py` 新增清除已選寶可夢的動作；128 個位於變更 Python 檔案中的固定字串 `tr()` 呼叫，其鍵值與英文 fallback 均符合新版主字串表。
- `services/pkhex/Program.cs` 新增其他訓練家持有紀錄限制的拒絕原因；經 `DisplayService` 的錯誤顯示路徑替換，補入 `messages.toml`。
- 同檔新增 GO 遭遇類型顯示與 Let's Go 的 GO Park 遭遇來源。參照 PKHeX.Core 26.10.18 的 `PogoType`、`IPogoSlot`、`EncounterSlot7GO` 與資料讀取格式，解析其 GO Park／HOME 遭遇表，共 170／1,173 個種類型態群組、3,691／18,774 筆紀錄，類型聯集為 23 種。沒有複製整套遭遇或名稱資料進語言包。
- 23 種 GO 類型中，「Egg → 蛋」沿用既有訊息，其餘新增 22 筆；加上持有紀錄限制的拒絕原因，`messages.toml` 共新增 23 筆。`templates.toml` 新增 2 筆，分別處理選單類型，以及含版本與日期範圍的遭遇描述；以 `message_kind` 保留並翻譯動態類型，其餘變數保持原值。`terms.toml` 無需修改。既有配信提示也統一採用「其他訓練家的持有紀錄」說法。
- `bin/swsh_host.py` 新增 `--raid-boss-as-is`，使用檔案原有資料而不依巢穴種子生成。七個工具共用此入口，`help.toml` 新增 7 筆說明；實際工具清單與 parser 比對沒有既有工具 ID、選項名稱或說明移除、改名或改寫。
- 新增巢穴種子錯誤與生成資訊在 CLI／紀錄中直接輸出；GUI 的獎勵查詢會攔截服務錯誤，再使用既有巢穴拒絕提示。沒有為無法在目前顯示路徑生效的英文紀錄新增對照。
- `docs/architecture.md`、`docs/gift_simulated.md`、`docs/gui.md`、`docs/hardware_esp32.md`、`docs/swsh_raid.md` 的 front matter 均未變，沒有新增或更名的遊戲側邊欄標題。
- Plugins API 仍為 1.12；外掛格式、載入與替換、簽章、Sources 解析及封裝工具沒有變更。
- PKHeX.Core 從 26.8.26 更新為 26.10.18。核對官方 tag `26.10.18`（`bfe89c74a3f5265805e364b79bc04ad38ebbc5ea`）：`GameLanguage`、`GameStrings`、`GameInfo` 與舊版相同，繁中名稱資源仍存在；pokeldn 的 `zh-TW` → `zh-Hant` 對應未變。配信資料由 PKHeX 提供，包含新增的 Z-A 配信紀錄，名稱與合法性報告仍走原有語系路徑。
- 其它變更包含巢穴種子與捕捉合法性、第三／四世代努力值所需經驗值、模擬器快取、韌體、建置依賴、上游版本檢查腳本與測試更新，沒有額外可由語言包替換的文字。

## 限制與待確認事項

- 本次未執行完整 GUI、Switch/開發板硬體、實際 PKHeX 服務或巢穴種子生成功能測試，未宣稱通過完整上游測試套件。環境未安裝 .NET、Flet 與 esptool，Python 檢查使用現有依賴（PyCryptodome 4.1.0、Trio 0.34.0），沒有以全套上游鎖定版本啟動 App；Flet 1.0.5 與各平台的實際畫面仍待實機確認。
- PKHeX 名稱語系相容性依來源與資源檢查；模擬服務測試只確認語系傳遞、錯誤與描述替換，不代表實際建立或捕捉的寶可夢已通過 PKHeX 合法性分析。
- 既有初訓家異色原因仍直接插入英文，遭遇版本名稱、地點語系與配信卡標題亦保留既有顯示限制。本次新增 GO 類型與日期範本沒有改動上游資料或地點的語系處理。
