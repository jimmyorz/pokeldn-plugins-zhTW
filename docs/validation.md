## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.10，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.9，再升級至 1.1.10，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；新增設定及動態錯誤訊息均正確替換，通過。
