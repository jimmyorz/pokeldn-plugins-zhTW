## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.13，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.12，再升級至 1.1.13，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；新增主字串、訊息對照、工具說明及保存開關均正確替換，通過。
- 在隔離目錄實際建立備份、檢查及還原，確認語言設定先暫存，於新 Python 程序套用後載入繁體中文；備份不包含語言包檔案，已安裝封裝、公鑰與簽章指紋保持不變，通過。

## 限制與待確認事項

- 本次未執行完整 GUI、實際 PKHeX 服務、Switch／開發板硬體、遊戲封裝讀取或 ROM／存檔傳輸。環境未安裝 .NET、Flet 與 esptool，Python 檢查使用現有依賴，未以全套上游鎖定版本啟動 App。
- 已核對新增功能的文字查詢、保存選項路徑及備份還原後的語言選取，但未實際檢視手機與桌面 GUI 的排版、尺寸與換行，也未執行真實交換、韌體燒錄或手機 USB 權限流程。
- 新備份功能有 7 種錯誤原因原文，部分直接顯示、部分插入已翻譯的外層訊息；這些原因未經語言包替換，單純加入對照無法生效。開發板像素畫面與 `[pokemon]` 保存紀錄也直接顯示英文。
- 配信已選取清單及標題搜尋仍直接使用原文；更新程式的兩段資料夾保護警告、單隻寶可夢檔案過大的錯誤也未經語言包替換，無法只靠新增對照生效。配信標題的實際 .NET 清單仍待完整 App 確認。
- 既有英文顯示範圍見 `docs/translation.md`，本次未擴大文件內文或原始紀錄的翻譯範圍。

`docs/maintenance.md` 保持不變；README 與 `docs/translation.md` 不記錄本地測試過程。
