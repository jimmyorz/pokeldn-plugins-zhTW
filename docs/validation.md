## 安裝與新程序載入

- 在全新隔離資料目錄安裝 1.1.17，啟用語言包並儲存繁體中文選擇，通過。
- 在另一隔離目錄先安裝 1.1.16，再升級至 1.1.17，確認判定為更新、公鑰相同，保留啟用狀態與語言設定，通過。
- 兩種安裝均另開新 Python 程序，確認版本、Plugins API 1.13、`zh-TW` 語系、圖示與八個來源檔案一致；新增譯文及動態錯誤範本均正確替換，通過。
